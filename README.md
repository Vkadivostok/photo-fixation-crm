# Мини-CRM «Фотофиксация» для автосервиса

Демонстрационное веб-приложение для фотоотчета по заказ-наряду: мастер сканирует или вводит номер заказ-наряда из основной программы, делает фотографии автомобиля до работ и после работ, затем печатает фотоотчет.

> Статус: демо-версия без серверной части. Клиентские данные, автомобиль, работы и стоимость ведутся в другой программе. Здесь хранится только номер заказ-наряда и фотографии, чтобы связать фотоотчет с основной карточкой клиента.

## Основные возможности

1. **Привязка к заказ-наряду**: номер можно ввести вручную или распознать камерой по QR/штрихкоду из другой программы.
2. **Фото до работ**: несколько фотографий автомобиля перед началом ремонта.
3. **Фото после работ**: несколько фотографий результата перед выдачей.
4. **Печатный фотоотчет**: отчет содержит номер заказ-наряда, дату и две группы фотографий.
5. **Демо-хранение**: данные сохраняются в `localStorage` через отдельный адаптер, который позже можно заменить на серверный API.

## Ограничения демо-версии

- `localStorage` не является надежным архивом доказательств: данные доступны только в текущем браузере и могут быть очищены.
- Локальная контрольная сумма помогает для демо, но не заменяет серверную подпись, журнал аудита и защищенное хранение файлов.
- Для рабочей версии нужен backend: авторизация, роли сотрудников, серверное хранение фото, хэширование файлов, журнал событий и экспорт отчета с серверной отметкой времени.
- Камера и сканер штрихкода требуют HTTPS или запуск на `localhost`.

## Локальный запуск

Приложение статическое, серверная часть не требуется.

```bash
# Если установлен Node.js
npx serve

# Если установлен Python
python -m http.server
```

Откройте `http://localhost:3000` или `http://localhost:8000`.
