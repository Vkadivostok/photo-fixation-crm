# Мини-CRM «Фотофиксация» для автосервиса

Мобильно-ориентированное веб-приложение для мастеров и приемщиков автосервисов, предназначенное для быстрой фотофиксации состояния автомобиля при приеме и сдаче работ. Защищает автосервис от необоснованных претензий клиентов и подтверждает качество выполненных работ.

## 🚀 Основные возможности

1. **Mobile-First UX / Темная авто-тема**: Современный интерфейс, стилизованный под автосервис (Carbon/Anthracite с неоновыми элементами). Удобно использовать со смартфона прямо в цеху.
2. **Связь с заказ-нарядом**: Позволяет вручную ввести номер заказа или считать его штрихкод/QR-код прямо с камеры устройства (использует библиотеку `html5-qrcode`). Для демонстрации на ПК встроена симуляция сканера.
3. **Интерактивная карта кузовных дефектов**: Мастер может кликнуть по детали кузова на SVG-схеме автомобиля, выбрать тип повреждения (царапина, вмятина, скол, трещина), сфотографировать дефект и установить метку на схеме.
4. **Фотофиксация по шагам**:
   - Шаг 1: Номер заказа и марка/модель.
   - Шаг 2: Внешний вид автомобиля (4 стороны по периметру).
   - Шаг 3: Состояние салона (приборная панель с пробегом, сиденья, багажник).
   - Шаг 4: Повреждения на схеме.
   - Шаг 5: Подпись клиента на экране устройства.
5. **Сохранение и сжатие фото**: Данные сохраняются в `localStorage`. Изображения сжимаются с помощью HTML5 Canvas перед сохранением, предотвращая переполнение квоты памяти.
6. **Выдача автомобиля (Фото результатов)**: Возможность зафиксировать финальный вид отремонтированных узлов и перевести заказ в статус «Выполнен».
7. **Генерация PDF-отчетов**: Печатная форма отчета об осмотре автоматически скрывает все лишние кнопки и навигацию при выводе на печать (`window.print()`).

## 🛠 Локальный запуск

Приложение не требует серверной части и готово к работе прямо из папки.

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Vkadivostok/photo-fixation-crm.git
   ```
2. Откройте `index.html` в браузере или запустите любой локальный статический сервер, например:
   ```bash
   # Если установлен Node.js
   npx serve
   
   # Если установлен Python
   python -m http.server
   ```
3. Откройте адрес `http://localhost:3000` или `http://localhost:8000` соответственно.
